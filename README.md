# florae · UX-прототип приложения «Похудение без диеты»

Кликабельный HTML-прототип на React + Babel (без сборки). Открывается двойным кликом по `App.html` или из любого статического хостинга (GitHub Pages, Netlify, Vercel).

## 🚀 Быстрый старт

**Локально:**
Открой `App.html` в браузере — всё работает без сервера.

**GitHub Pages:**
1. Settings → Pages → Source = `main` / root
2. Открой `https://ledydy47-cmd.github.io/eda/App.html`

## 📁 Структура

```
├── App.html                       # ← финальное приложение (все 20 экранов)
├── Prototype.html                 # ранняя версия с переключателем 3 тем
├── Prototype v1 (3 темы).html     # архивная копия
├── components/
│   ├── tokens.jsx                 # дизайн-токены (палитра, шрифты)
│   ├── ui.jsx                     # общие UI-примитивы (кнопки, иконки, кольца)
│   ├── PhoneShell.jsx             # iPhone-фрейм со статус-баром
│   ├── TabBar.jsx                 # нижняя навигация
│   ├── AppFinal.jsx               # корневой компонент + роутинг + сайдбар
│   └── screens/
│       ├── Onboarding.jsx         # splash, value slider, goal, plan-gen, paywall
│       ├── OnboardingQ.jsx        # анкета Q2-Q5 + регистрация
│       ├── Today.jsx              # главный экран «Сегодня»
│       ├── Meals.jsx              # питание · день
│       ├── Workout.jsx            # активное упражнение
│       ├── Beauty.jsx             # библиотека процедур
│       ├── Profile.jsx            # профиль + график веса
│       └── Details.jsx            # bottom-sheet, полный рецепт, обзор трен., награды, награда-оверлей
└── tweaks_panel.jsx               # (не используется в финале)
```

## 🎨 Дизайн-система

**Тема:** Bold Playful (единственная в финале)
- Фон: `oklch(98% 0.004 60)` — тёплый off-white
- Акцент: `oklch(68% 0.18 25)` — коралловый
- Успех: `oklch(62% 0.14 155)` — свежий зелёный
- Шрифты: Space Grotesk (display), Inter (body), JetBrains Mono (метки)
- Скругления: 14 / 22 / 30 / 40 px

## 🗺️ Карта экранов (20)

**Онбординг** (4): Splash → Value slider ×3
**Анкета** (5): Q1 Цель → Q2 Зоны → Q3 Параметры → Q4 Активность → Q5 Питание
**Конверсия** (3): Генерация плана → Paywall → Регистрация
**Основное** (8): Сегодня, Питание, Рецепт, Тренировка (обзор), Активное упражнение, Красота, Профиль, Все награды

## 🧭 Управление

- Сайдбар слева — прыжок на любой экран
- Стрелки ←/→ вверху — по всей карте по порядку
- Клик по табу внизу мокапа — переключение основных зон
- Клик по карточке «Ужин» на экране «Сегодня» → bottom sheet → «Съедено» → оверлей награды

## 🔧 Технологии

- React 18 (UMD, без сборки)
- Babel Standalone для JSX прямо в браузере
- Google Fonts: Space Grotesk, Inter, JetBrains Mono, Fraunces
- localStorage — сохраняет текущий экран

## 📝 Заметки

Изображения (еда, тренировки, косметика, аватары) — стилизованные полосатые placeholder'ы с подписью, что должно там быть. Реальные фото добавляются клиентом.
